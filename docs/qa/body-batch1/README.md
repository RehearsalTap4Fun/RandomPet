# 短腿圆身第一批验收

## 交付

- 1 张真实透明主体；11 件异变复用现行 PNG，按新体型单独适配。
- 16 张原生 1254 × 1254 组合图，位于 `samples/`。
- `index.html` 提供深浅背景、128/256 像素缩略及点击原图。
- `report.json` 记录资源和代码哈希、16 个可回放规格、18 个旧体型代表样本对比；`profile-snapshot.json` 固定本轮实际美术参数。

## 验证结果

- 16 / 16 组合 JSON 序列化前后 RGBA 像素哈希一致。
- 18 / 18 旧体型样本与原基线像素一致，覆盖六种毛色及基础、耳尾替换、叠加三种场景。
- 新主体及引用的 11 件素材均通过文件哈希、1254px 尺寸、真实 alpha 和非空检查。
- 16 个样本均无 alpha 大于 8 的像素接触画布最外边，分叉尾越界已修正。
- 全项目 100 项测试通过；TypeScript 检查、工作台与孵化 SDK 构建通过。
- 孵化接入 24 项检查通过，包括合成器重构前、鬃毛修正前的存档恢复、新旧异变回放、并发隔离和资源错误处理。完整记录见 `../integration-verification.json`。

## 目视检查与修正

- 查看全部 16 张的深浅背景及 128/256px 表现；重点放大鳍耳、颈膜、分叉尾和五部位叠加。
- 纯绿底抠图的边缘处理加入邻近干净毛色估计，降低橘色毛发上的绿边，同时保留白毛和胡须。
- 分叉尾向左调整 30px，完整保留双叉末梢与画布留边。
- 旧尾移除轮廓按新圆身重画，清除了尾根上方残留的旧尾小片。
- 用户指出小狮鬃层级不正确，确认修复后，将鬃毛移到肩胸前方并加入头部遮罩，恢复脸颊/下巴在前、鬃毛居中、翅膀在后的关系。缩放从 `0.82 × 0.38` 改为 `0.70 × 0.58`，减少横向拉宽与纵向压扁。
- 修正仅改变 06、16 号，其他 14 个样本像素不变；两张图的中央脸部区域（眼、鼻、嘴、脸颊）与各自修正前像素完全一致。前后对比见 `mane-fix/index.html`，原图、原 profile 和原验证记录保存在同目录。
- 圆身会遮挡更多小翅膀；当前保留为轻量异变，小狮鬃修正后的五部位叠加效果已获用户批准。
- 生成绿底中间图并非无损像素提取，主体细毛相对浅底概念图存在变化；用户已于 2026-09-16 对修正后的透明成品及本批组合明确批准。

## 重跑

在项目根目录先运行 `npm run dev`，再执行：

```powershell
node scripts/prepare-body-batch1.mjs
node scripts/review-body-batch1.mjs
npm test
npm run build
npm run verify:integration
```

抠图脚本仅从已保存的绿底图确定性重建透明主体；如果修改抠图参数，必须重新检查结果并更新 profile 中的主体哈希，不能绕过资源校验。
