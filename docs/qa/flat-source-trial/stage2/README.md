# 第二阶段：像素组合与体型适配

## 当前验收状态

用户已明确回复“验收通过”，本批 10 个适配组合全部通过美术验收，见 `approval.json`。它们与首批 4 个组合一并纳入像素美术包 1.1.0。下面保留制作期说明；原始报告及图像字节不改写，以供验收摘要校验。Nutri 正式运行时接入另行推进。

## 本批范围

在已确认的首批 C 列风格上，新增鳍耳、前胸小狮鬃、小尖牙主体和短腿小尖牙主体四张源图。只使用橘白花纹，不扩充其他花纹与配色。15 张候选与对照已经生成，其中本批 10 张适配组合已通过验收。

入口 `index.html`；10 张主要组合总览 `comparison.png`；工程记录 `report.json`。额外的 5 张包括两种体型各自的旧层级鬃毛／全叠加，以及原体型微张嘴对照。

## 实际验证与修正

1. **小尖牙**：首版在原始 Nutri 滤波和缩小后消失。扩大暗色嘴部与双牙后，64px 图中保留了两侧白色牙齿；表情比毛绒版更夸张，现已获得用户认可。`mouth-detail.png` 是最终原体型 64px 图的最近邻局部放大。
2. **鳍耳**：首版内部鳍骨对比不足。改用深色粗鳍骨，保留蹼形轮廓；生成器未严格遵守坐标，使用 profile 校准尺寸与位置。
3. **鬃毛**：Nutri 现有后层放置遮掉了前胸部分。实验配置将鬃毛绘制到 subject，并先在鬃毛图层上应用脸部遮罩。首版过宽、中央白色与胸口混在一起，现已收窄并简化为金棕色。
4. **短腿体型**：使用独立主体源图及美术 profile；尾巴擦除区域复用短腿试验的几何，避免原体型的擦除区切到更宽的臀部。

修正前总览和报告保存在 `before-fix/`，初始源图在 `docs/art/flat-source-trial/stage2/attempts/`。

## 工程结果与边界

- 使用 Nutri `b7addf5914c18d8904103ba87576b196f3f75d9b` 的原始像素化脚本；Nutri 受 Git 跟踪的源代码未修改。
- 两套美术配置各转换 44 张已有资源。其中 6 张走平涂输入，其余 **38 张回退图层**分别与首批毛绒基线逐文件相同。这不是新增 88 张美术。
- 全部 88 张图层为 64×64，alpha 只有 0/255；15 张合成可确定性回放。
- 六张含鬃毛的适配样本，眼、鼻、嘴矩形区域 `x=16..36, y=14..31` 与相同组合去掉鬃毛时逐像素一致。矩形外的脸颊和下巴边界仍通过目视检查，不把矩形检查夸大成全脸自动验收。
- 首批已批准的三张源图指纹未变。
- **不是可直接上线的替换包**：前胸层级、脸部遮罩、短腿体型映射和尾部擦除区由 QA 适配器提供。正式接入需要把这些字段纳入像素美术配置并让消费端读取。
- 原始大图仍存在局部渐变与生成偏移，不能保证单靠提示词固定坐标或严格限制色数。

## 对生产路线的启示

64/128px 展示可以继续沿“平涂源图＋像素化”方向验证；需要按目标分辨率设计性状大小，而不是机械缩小毛绒造型。后续应让同一份表现型分别映射到毛绒、像素美术配置，定位、擦除、遮挡和调色各自版本化。本批只验证这一方向的局部可行性，未实现基因继承系统或完整的多风格生产接口。
