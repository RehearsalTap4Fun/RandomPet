### npm 10 argument interception

The plan's literal command `npm run acceptance:generate -- --version 0.3.0` exits 0 on npm `10.9.2` but is intercepted as npm's own global `--version`: it prints `10.9.2` and does **not** invoke the generator. It is deliberately not counted as a generation pass. Default v0.3 generation and the direct, non-conflicting `--catalog-version 0.3.0` invocation above are the actual byte-reproduction evidence. An attempted npm-form `--catalog-version 0.3.0` was also not counted because npm stripped the option name; the direct `tsx` invocation is authoritative.
