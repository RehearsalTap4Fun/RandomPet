# v0.3 Task 9 verification boundary

`npm run verify:task9` is the complete Task 9 technical gate. It runs type
checking, all unit and integration tests, coverage, the v0.1/v0.2/v0.3
production catalog validators, the production build, render goldens, browser
E2E, and performance checks.

The root `npm run verify` intentionally adds v0.2 whole-creature acceptance
generation and human-approval verification after that technical gate. Until
the Task 10/11 approval and default-version work records the required v0.2
full-composite sheet, manifest, and user acceptance, its expected terminal
result is `COMPOSITE_REVIEW_INVALID`. Task 9 must not fabricate that approval
or weaken the root release gate.
