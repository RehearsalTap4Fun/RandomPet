# QMonster v0.5 Single-Head Long-Tail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release an immutable v0.5 catalog that generates one head only and limits active tails to none, cat-long, and dog-long components.

**Architecture:** v0.5 is a complete, immutable interface-catalog release derived from v0.4’s non-tail resources. Version-aware loaders, validators, Web imports, and the hatchery contract gain exact `0.5.0` support. The new catalog removes the double-head modifier and replaces all v0.4 active tail parts with six rig-specific, tail-root-connected structural variants.

**Tech Stack:** TypeScript 7, Vitest 4, React 19, Vite 8, Playwright Chromium, Sharp, existing QMonster catalog/connector validation.

**Spec:** `docs/superpowers/specs/2026-09-03-qmonster-v0.5-single-head-long-tail-design.md`

## Execution Dependency Clarification

The v0.5 runtime files must exist before the Web registry can import
`catalog/v0.5.0/catalog.json`. Execute the source-image staging and the
catalog-assembly work from Task 2 first, but defer Task 2's final production
validation until the exact-version predicates from Task 1 are registered.
Then complete Task 1, return to finish Task 2 validation/publication, and
continue with Tasks 3–5. This only corrects implementation order; it does not
change the approved release contract.

## Global Constraints

- Use exact catalog and renderer version `0.5.0` for every v0.5 artifact and generated spec.
- Do not modify v0.4 catalog files, assets, source index, review data, or existing acceptance batches.
- v0.5 mutation candidates exclude `mutation_double_head`; other existing mutation and aberration candidates remain.
- v0.5 tail candidate IDs are exactly `tail_none`, `tail_cat_long`, and `tail_dog_long`.
- `tail_cat_long` and `tail_dog_long` each ship blob, biped, and floating variants with one `tailRoot` plug node on `rearAppendage`.
- New tail assets are transparent 1024×1024 components with no fan, fin, fork, mushroom cluster, or detached subcomponent.
- Do not auto-generate, visually filter, replace, or approve a user-review batch during implementation.
- Existing v0.4 specs remain loadable through their exact catalog; version mismatches fail closed.
