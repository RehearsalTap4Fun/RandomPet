# QMonster Creator v0.3 Interface Components Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace cutout-style structural composition with exact-rig head, body, limb, tail, and extra-appendage variants joined by bounded, material-aware soft transition bridges.

**Architecture:** Catalog `0.3.0` introduces receiver/plug connector profiles, rig-specific structural variants, and catalog-level bridge definitions. The generator excludes incompatible pairs before selection; renderer `0.3.0` solves connectors and composites back bridge, structure, and front bridge as a distinct path while preserving exact `0.1.0` and `0.2.0` behavior.

**Tech Stack:** TypeScript 7, Zod 4, React 19, Canvas 2D, Sharp, Vitest, Playwright/Chromium, built-in Codex image generation for production structural raster assets.

**Spec:** `docs/superpowers/specs/2026-08-24-qmonster-v0.3-interface-components-design.md`

## Global Constraints

- Preserve exactly 14 visual slots: `bodyFrame`, `headShape`, `eyes`, `mouthShape`, `oralDetail`, `headAppendage`, `arms`, `legs`, `tail`, `extraAppendage`, `surfaceMaterial`, `pattern`, `colorScheme`, `effect`.
- Preserve exactly 8 semantic slots, 3 themes (`deep-sea`, `fungal`, `shadow`), and 3 rigs (`blob`, `biped`, `floating`).
- Catalog and renderer `0.3.0` are exact-version paths; `0.1.0` and rejected `0.2.0` remain exact read-only paths with no fallback or silent migration.
- Structural slots are `bodyFrame`, `headShape`, `arms`, `legs`, `tail`, and `extraAppendage`; all other visual content is retained but re-anchored to v0.3 resolved structure.
- A structural part may be selected only when its exact-rig variant, matching receiver/plug class, supported material family, and a bridge within both warp limits exist.
- Never special-case a seed, acceptance index, part pair, or screenshot coordinate.
- Bridge coverage at each end is at least `0.9`; largest connected structural alpha is at least `0.99`; connector centerline gap is at most 2 pixels at 1024 output; every visible arm and leg has at least `0.65` alpha outside body alpha.
- Eyes and mouth retain inside ratio `>= 0.8` and visible ratio `>= 0.85`; auto-generated strong features remain `<= 2`; optional none rates remain `[0.35, 0.5]`.
- Biped 16-combination structural slice requires explicit user approval before producing other rig variants. Full v0.3 21-entry contact sheet requires a second explicit user approval before changing the default catalog.
- Use the built-in `image_gen` path for structural raster production. Inspect every local reference with `view_image` first, use separate generation calls for distinct assets, and copy every accepted output into `asset-source/v0.3.0`.
- Current uncommitted Task 7 work exists only in this linked worktree. Do not create another worktree before Task 1 snapshots it into Git history and returns the checkout to a clean state.
