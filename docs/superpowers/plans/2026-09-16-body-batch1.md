# Short-legged round body pilot implementation plan

> **For agentic workers:** Execute this bounded art pilot inline, following the existing approved scope and the executing-plans workflow. Do not dispatch additional agents or broaden into a production genetics migration.

**Goal:** Produce one transparent short-legged round body and the agreed 16 reproducible combination samples.

**Architecture:** Keep the approved phenotype (body identity, orange-white coat, small fangs) separate from artwork paths and template geometry. Share the existing Canvas composition engine between the legacy renderer and a versioned study entry point. The study does not change legacy generation probabilities, save formats or the production catalog.

**Tech Stack:** TypeScript, Canvas 2D, existing PNG assets, image_gen, Playwright, Vitest.

**Spec:** `docs/art/2026-09-16-body-batch1.md`

## Global constraints

- Exactly 16 study samples: base, 11 single mutations, 4 specified stacks.
- User approved the base shape in the latest reply `1`; extracted art and composites require separate visual review.
- Preserve all legacy resource bytes and output pixels.
- Genuine alpha is required; an opaque/checkerboard image must fail the resource check.
- No additional coats, expressions, patterns or production rollout in this pilot.
