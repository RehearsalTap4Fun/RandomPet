# QMonster v0.5 单头与长条尾巴设计

日期：2026-09-03
状态：待实现

## 目标

v0.5 的随机基因规则只生成一个完整头脸组，并把活动尾巴收束为可稳定连接躯干的长条形态。新输出不得出现双头、鱼尾、扇面尾、簇状尾或分叉尾。

## 版本与兼容性

- 新规则发布为精确版本 `0.5.0`，不改写 v0.4 catalog、资产或历史基因组。
- v0.4 继续用于先前已生成的存档和孵化器接入；其 `mutation_double_head`、`tail_fish_fan`、`tail_soft_curl`、`tail_mushroom_cluster` 保持历史可读。
- v0.5 的生成器、Web 默认 catalog 和孵化器适配器都以 `0.5.0` 为当前版本，并在版本不匹配时沿用现有的失败关闭校验。

## 生成规则

### 头部

- 从 v0.5 的 mutation 候选池移除 `mutation_double_head`。
- 保留其他既有 mutation 与 aberration；它们不得复制或新增 `headShape`、`eyes`、`mouthShape`、`oralDetail`、`headAppendage` 的第二套节点。
- 每一份 v0.5 `MonsterSpec` 恰有一个 `headShape` 节点及其所属的一套脸部安全区。

### 尾巴

v0.5 的 `tail` 槽位仅允许下列 part id：

| Part id | 形态 | 规则 |
| --- | --- | --- |
| `tail_none` | 无尾 | 显式空组件，不创建尾根连接。 |
| `tail_cat_long` | 猫尾 | 细长、柔软、单根、轻微弯曲，向下或侧后方自然延展。 |
| `tail_dog_long` | 狗尾 | 稍粗、单根、自然下垂或上扬，末端圆润。 |

- 两种活动尾巴不含鱼鳍、扇面、蘑菇簇、分叉或独立漂浮部件。
- `tail_cat_long` 与 `tail_dog_long` 都需要 blob、biped、floating 三个 rig 变体；每个变体均连接 `bodyFrame.tailRoot`。
- 每个活动尾巴变体是透明 1024×1024 组件，只有一枚后置结构节点；尾根 plug 位于现有 tail-root 指引内，轮廓、前景和背景遮罩均完整声明。
- 尾巴绘制层保持 `rearAppendage`。躯干与尾根桥接维持当前背后/前景两次 pass，使躯干覆盖根部接缝。

## 资产与 catalog 契约

- 建立 `packages/asset-catalog/catalog/v0.5.0/catalog.json` 与对应 v0.5 资产、连接器和哈希清单。
- catalog 只列出 v0.5 的三个尾巴候选；旧鱼尾、卷尾和菌簇尾不复制进 v0.5。
- 新 tail part 的 `semanticTraitId` 分别是 `tail_cat_long`、`tail_dog_long`；尾巴仍映射至既有 `appendage` 语义槽位。
- 每个新增资产都必须通过现有透明度、边界、socket、connector 与 source-rich 校验；不得用整张不透明贴片伪装尾巴。

## Web 与孵化器接入

- Creator Web 能加载并生成 v0.5，并把 `catalogVersion`、`rendererVersion` 写为 `0.5.0`。
- 孵化器接入文档增加 v0.5 的协商示例，明确当前允许 mutation 与 tail part id；版本不匹配不得降级猜测。
- 现有 v0.4 导入与只读历史预览继续走 v0.4 catalog，不自动迁移为 v0.5。

## 验收与回归

1. catalog 校验覆盖 v0.5 的六个活动尾巴 rig 变体、三个尾巴候选和所需连接器遮罩。
2. 固定种子覆盖 normal、mutation、aberration 三种模式；v0.5 不产生 `mutation_double_head`，attachment tree 只含一个完整头脸组。
3. 尾巴候选只会是 `tail_none`、`tail_cat_long`、`tail_dog_long`；任何旧尾巴 id 在 v0.5 spec 中均被拒绝。
4. 六个活动尾巴变体通过连接覆盖率、外露比例、结构连通率和画面边界检查。
5. v0.4 旧 spec 仍可用 v0.4 catalog 渲染；v0.5 的孵化器契约测试验证版本与特征白名单。

## 非目标

- 不删除 v0.4 的历史资产或已生成批次。
- 不重做身体、头部、四肢或纹理层设计。
- 不自动生成、审核、筛选或替换用户审核批次。
