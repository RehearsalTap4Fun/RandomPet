# 不规则涂鸦背景美术批设计

日期：2026-09-20

状态：设计已确认，等待规格复核

范围：先完成三张背景美术与验收证据；本阶段不升级表现型 schema、catalog 或正式像素包。

## 目标

为像素小管家制作 N／R／L 三档不规则涂鸦背景。背景在猫和全部部件之后绘制，通过色彩和主题内容表达稀有度，并保持六种毛色在 64×64 下清晰可辨。

本批通过后再单独设计和实施第十个表现型性状、catalog 新版本及第七个绘制步骤。

## 方案选择

采用程序直接生成 64×64 像素图层。轮廓、调色板和装饰笔触均由数据定义，输出使用固定 PNG 参数，因此能够精确检查约束并稳定重建。

未采用的路线：

- 手工修改参考图：调整快，但生成过程难以复现。
- ImageGen 概念图再像素化：变化丰富，但容易产生断开的色块、抗锯齿和明度偏差。

## 三档美术

| 档位 | 暂定资源 ID | 主题 | 调色方向 |
|---|---|---|---|
| N | `doodle-horizon` | 米白横向涂抹块与一至两笔短弧线 | 米白、暖灰、浅杏 |
| R | `doodle-leaf-shadow` | 浅绿底与三至五组叶影 | 浅绿、鼠尾草绿、暖白 |
| L | `doodle-rainbow-trail` | 浅紫底、青橙虹弧与米白星轨 | 浅紫、青、橙、米白 |

资源 ID 在正式 catalog 接入前仍可调整；本批审批以图层文件摘要为准。

## 轮廓规则

三档保持相近面积，并参考以太猫使用同一套“横向不规则涂抹块”轮廓语言：多段圆润横带相互搭接，在左右形成大小不同的凸起、凹口与刷痕端部。猫遮住中部后，背景主要从头顶和身体两侧露出；每档拥有不同的横带高度和不对称起伏。稀有度不通过扩大背景表达。

每张图必须满足：

1. 64×64、透明背景、二值 alpha。
2. 所有非透明像素构成一个四邻连通区域。
3. 四边至少保留 1px 透明空白；不得触碰画布边缘。
4. 轮廓纵向控制在约 `y=8–54`，不延伸为落地底座；猫脚可落在背景轮廓之外。
5. 四角保持透明，整体不得读成矩形卡片或相框。
6. 面积目标为 1,900–2,450px，保证横向包围感，同时留下足够页面底色。
7. 装饰笔触必须与底色区域相连，不能形成独立散点。
8. 允许猫、翅膀、尾巴、光环和其他部件自然溢出背景轮廓。

## 明度与颜色

明度按 WCAG 相对亮度计算：

- 三档底色均不得妨碍燕尾服与金豹点毛色辨识。
- L 档底色相对亮度必须不低于 `0.55`。
- L 档任一装饰颜色相对亮度必须不低于 `0.35`。
- 输出使用固定的小型调色板，不使用半透明、抗锯齿、渐变或抖动。
- 稀有度由色相数量、主题完整度和笔触层次表达，不依赖深色背景。

## 生成与合成

新增一个独立构建脚本，职责仅包括：

1. 根据三份轮廓与装饰数据生成 RGBA 像素层。
2. 写出三张确定性的 PNG。
3. 执行尺寸、alpha、连通性、边缘、面积和明度断言。

验收合成继续复用正式 1.5.0 的资源、profile 与 `pixel-rgba-v1` 描边／叠加实现。背景在验收合成中作为最先绘制的 `frame` 图层，无 `clear`、无 `occlusion`。本阶段的临时合成适配只存在于 QA 脚本，不改变生产 schema 或 renderer。

## 验收矩阵

验收页面共 21 格：

### 毛色对比 18 格

三张背景分别搭配六种毛色：

- `orange-white`
- `brown-tabby`
- `tuxedo`
- `calico`
- `colorpoint`
- `rosetted`

统一使用标准体型和固定脸型，减少无关变量。重点检查燕尾服的深色区域和金豹点的高密度花纹。

### 满配压力测试 3 格

每张背景各合成一只满配猫，使用已批准的高可见度部件组合，检查光环、翅膀、尾巴等溢出背景后的层级与构图。若五条新进化链尚未登记正式包，QA 脚本可直接引用其已批准图层，但必须在报告中标记为验收素材，不得暗示已经进入正式 catalog。

页面同时显示 3 倍最近邻预览和原生 64px，并提供深浅页面底色切换。

## 报告与验收证据

QA 报告记录：

- 三张背景 PNG 的 SHA-256、像素边界、面积、连通分量数和调色板。
- 各颜色的相对亮度及约束结果。
- 21 个组合的表现型、使用资源、PNG SHA-256 和合成 RGBA SHA-256。
- 基础 catalog 路径、renderer 版本和生成脚本摘要。

用户通过页面后，再生成独立 `approval.json` 固定用户原话与精确文件摘要。美术审批状态为 `art-approved-registration-pending`。

## 验证

1. 连续两次重建，确认三张图层、21 个样本和报告逐字节一致。

3. 运行 `git diff --check`。
4. 逐项复核自动约束，并目视检查 21 格页面。
