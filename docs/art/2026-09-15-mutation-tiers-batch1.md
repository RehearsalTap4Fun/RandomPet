# 小猫异变分层 · 批次 1 规格（孵化器 × QMonster v0.10）

日期：2026-09-15。状态：孵化器侧规则 v2 已实现并可预演；RandomPet 侧待出图与目录扩展。

## 1. 目标

在 v0.10「小猫组合」的 5 个异变位置上引入稀有度分层。现有 6 件（鳍耳、分叉尾尖、小狮鬃、小翅膀、小龙角、鹿角）SDK 命名即 small-*，全部定为 **N 级**，并各自作为一个主题的标志异变。**R / L 级由新素材承担**：更大、更亮、一眼可辨，且在 200px 缩略图下仍清楚。

批次 1 只做 5 件、全部与花纹无关（各 1 张 PNG，不需要 6 花纹重绘、不需要登记缩放位移）：

| id | 位置 | 层 | 中文名 | 命名字 | 一句话 |
| --- | --- | --- | --- | --- | --- |
| `frill-neck` | neck | R | 伞蜥颈膜 | 膜 | 伞蜥式半透明颈膜，撑开在头后 |
| `feathered-wings` | back | R | 羽翼 | 羽 | 乳白鸟翼，明显高过肩线，比小翅膀大一倍以上 |
| `flame-tail` | tailTip | R | 焰尾 | 焰 | 整条尾巴替换为燃着橙金火焰的尾 |
| `halo` | crown | L | 光环 | 环 | 头顶悬浮的金色发光环，不接触身体 |
| `dragon-wings` | back | L | 龙翼 | 翔 | 大型深色骨架 + 橙粉膜的龙翼，张开高过头顶 |

耳位置暂不加（耳件要清除原耳并带周边毛色，必须按 6 花纹各出一张，留到批次 2，候选：蝠翼耳 R）。

## 2. 画布几何（实测，1254×1254 最终坐标）

所有叠加件除耳以外都画在**身体后面**（renderer 先画 back/crown/neck/tailTip 到底层，再盖上身体+耳）。因此被身体挡住的部分画不画都无所谓，**关键是露在轮廓外的部分要足够大**。

## 3. 每件的制作要求

通用：1254×1254 真实 alpha 透明 PNG；毛绒玩偶写实风，左上主光，与主体一致；不画猫、不画地面、不画阴影；不得出现第二套器官；在深色/浅色背景各检查一次毛边；缩到 200px 仍可辨。

1. **halo（L，crown）**：金色细环，略带透视的椭圆，柔和暖光晕，无链无支撑。环中心约 (560,45)，横跨 x 420–700、y 15–85；耳尖会盖住环的一小段（耳在前），这正是"悬浮在头顶"的效果。
2. **dragon-wings（L，back）**：一对大型龙翼，深炭棕骨架 + 与鳍耳同族的橙粉半透明膜，无鳞片。翼根从肩后 y≈560 出发，向上外张开：左翼尖约 (60,180)、右翼尖约 (1200,150)。躯干区域 x 330–1000 / y 560–900 会被挡住。整体限制在 x 20–1240、y 120–940。
3. **feathered-wings（R，back）**：一对乳白色分层羽翼，明显高过肩线，翼尖约 (170,300) 与 (1090,290)，暖色阴影。限制在 x 100–1160、y 250–880。
4. **frill-neck（R，neck）**：伞蜥式半圆颈膜，橙粉半透明膜 + 深色放射骨条，撑开在头颈后方，横跨 x 150–1000、y 330–900，下缘藏到胸后，上缘到耳尖下方。被头挡住的中心区（x 330–900 / y 180–700）可留空。
5. **flame-tail（R，tailTip）**：整条火焰尾，橙金主体、黄色亮芯、红橙边缘，走原尾路径：尾根约 (900,1090) 藏在右后臀后，向右扫到 (1090,860)，上升到 (1030,560)，尾尖约 (1000,400)。整体限制在 x 880–1235、y 380–1135（必须盖满尾部清除多边形），允许轻微暖光但不出框。

提示词草案见同目录 `feline-mutation-tiers-batch1-prompts.json`（沿用 v0.10 provenance 的格式：image 1 = 橘白微张嘴主体作定位参考）。

## 4. RandomPet 侧改动清单（master / v0.10 代码）

1. `packages/generator-core/src/feline-combination.ts`：`COMBINATION_OPTIONS` 枚举加 `crown: +halo`、`neck: +frill-neck`、`back: +feathered-wings, +dragon-wings`、`tailTip: +flame-tail`。
2. `packages/asset-catalog/src/feline-combination-catalog.ts`：`FELINE_MUTATION_IDS` 加 5 个 id；`auditFelineCombinationCatalog` 要求每个花纹都有投影，与花纹无关的件像 `dragon-horns` 一样在 6 个花纹下都指向同一资源。
3. `packages/renderer-canvas/src/feline-combination-render.ts`：变换目前按位置写死（back→smallWings、neck→smallLionMane、tailTip→forkedTailTip，crown 已按 id 区分）。新 id 需要按 id 选变换，并对批次 1 全部使用恒等变换（按最终坐标制作）。`feline-combination-registration.json` 无需新增（非花纹绑定）。
4. 目录 `catalog.json` 加 5 条 `resources` 与 6×5 条 `mutations[coat][id]`，`review: pending` 直到人工批准。
5. 版本：`catalogVersion` / `schemaVersion` 字面量与快照由 RandomPet 侧决定；孵化器只钉 `runtimeRevision`。改动后 `node scripts/update-release-snapshot.mjs` → `npm run typecheck && npm test && npm run build` → 孵化器 `npm run sync:hatchery` 并更新 `src/qmonster/feline/sdk.ts` 的 `FELINE_RUNTIME_REVISION`。
6. 验收：864 → 6×3×(3×2×2×3×2)=1296 组合全览；重点看羽翼/龙翼露出量、光环与耳的遮挡、焰尾对清除区的覆盖、颈膜与狮鬃互斥后的单独效果。

## 5. 孵化器侧规则 v2（已实现，`src/qmonster/feline/rules.ts`）

- 判定 → 处数：正常 0–1（35/65）、变异 2–3（60/40）、畸变 3–5（40/40/20）。
- 每次抽取先掷层：正常 N82/R15/L3，变异 N45/R40/L15，畸变 N30/R40/L30；层内按主题亲和加权（标志 ×6、次级/亲和 ×3、其他 ×1；畸变把本主题件压到 ×0.25）。
- 正常态掷到 N 层时首件 80% 直接给标志异变；变异态首件必为标志。
- 稀有度 = max(所选异变最高层, 处数层)，处数层 0–1 N / 2 R / ≥3 L。
- 主题亲和（R/L 更常落到）：深海←颈膜；幽影←龙翼；炎烬←焰尾、龙翼；林苔←颈膜、羽翼；云翼←羽翼、光环；曜庭←光环、羽翼。
- 可用性按目录实际投影过滤：素材未到的件不会被渲染到；试验页"分布预演"用全量登记表预演到位后的经济。
