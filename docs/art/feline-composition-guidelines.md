# 猫型组合生成：有效制作规则

本指引整合 v0.9.2–v0.9.4 与 2026-09-15 花纹、表情、异变和尾巴修复的经验。当前素材的原始来源与批准记录保存在 `docs/releases/v0.10.0/provenance/`，路径映射见同级 `migration.json`。

1. **先保证动物完整性。** 使用固定坐姿和同一母版，不能只凭锚点或包围盒对齐就判定可拼接；必须检查轮廓粗细、弯曲切线、光照、毛向和负形。
2. **完整表情与主体一起制作。** 每种花纹各有自然微张嘴、两颗小牙、轻吐舌三张完整主体图。独立画椭圆嘴、牙齿和舌头曾造成突兀贴片，不再采用。
3. **花纹遵循毛色分布。** 虎斑、双色、三花、重点色、豹点体现为毛发上的图案，不附加无意义的线条、悬浮纹理和装饰面片。
4. **不同位置允许叠加，同位置互斥。** 额顶的小龙角和鹿角互斥；耳、颈、背、尾可共存。不要为了避免制作问题而删除所有异变组合。
5. **异变必须适合正面坐姿。** 背鳍表现弱，不采用；颊侧鳃羽被否决，改为小狮鬃。翅膀和鬃毛利用身体遮挡根部，同时检查其是否仍清楚可见。
6. **替换结构，避免重复器官。** 鳍耳清除原耳；分叉尾使用完整可见尾，根部藏在臀部后。尾干中段的两段拼接，即便加渐隐，也不能修复粗细、曲率或纹样断层。
7. **透明必须有真实 alpha。** 棋盘格不等于透明。验证解码尺寸、alpha、非空像素，再在深浅背景检查毛边。实色棋盘格提取失败时，先生成纯色背景，再做背景提取；失败图不能覆盖最终图。
8. **所有入口共用渲染器。** 工作台、导出、批量验收和孵化端都调用相同的规格解析、目录解析和 Canvas 合成入口。禁止为截图另写一套缩放/裁剪逻辑。
9. **工程测试与美术验收分开。** 数百项规则测试不能证明嘴巴或尾巴自然。保留实际组合全览与局部放大，批准记录绑定具体资源和源码哈希；新制作素材不自动继承参考图批准。
10. **清理不得破坏回放和溯源。** 当前目录引用、旧存档使用的版本、最终制作来源、提示词和用户批准均保留；临时预览和可重建的构建产物可删除。接口接入以 `docs/integration/qmonster-hatchery-integration.md` 为准。
